# AI-Based Phishing Email Detection using Machine Learning and Transformer Models

## Project Overview
This project investigates phishing email detection using traditional machine learning and transformer-based deep learning models.

## Models Used
- Logistic Regression
- Random Forest
- Linear SVM
- Multinomial Naive Bayes
- XGBoost
- Bidirectional LSTM
- DistilBERT
